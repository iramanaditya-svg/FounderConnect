# FounderConnect

FounderConnect is a full-stack platform designed to connect Startup Builders, Professionals, and Investors in one ecosystem.

The platform allows users to create role-specific profiles, manage startups, discover investment opportunities, connect with other users, and communicate through the platform.

## Features

### Startup Builder

- Create and manage startup profiles
- Edit startup information
- Manage multiple startups
- View applicants
- Manage hiring activities
- Raise investment
- View investment requests
- Manage connections
- Upload profile picture
- Edit profile
- Add and remove roles
- Profile management
- Change password

### Professional

- Create a professional profile
- Manage professional information
- Discover opportunities
- Manage applications
- Manage connections
- Upload profile picture
- Edit profile
- Add and remove roles
- Profile management
- Change password

### Investor

- Create investor profile
- Select preferred industries
- Select preferred investment stages
- Discover startups
- Manage investment activities
- Manage connections
- Upload profile picture
- Edit profile
- Add and remove roles
- Profile management
- Change password

### Public Profiles

FounderConnect provides public profiles where users can:

- View another user's profile
- View profile picture
- View username and name
- View active roles
- View biography
- View professional information
- View location
- View startups
- View role-specific information
- Connect with other users
- Start conversations
